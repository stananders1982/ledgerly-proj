# Sales Pulse Dashboard

Build a business finance dashboard for a sales company.

Features:

1. Track leads
- Lead source
- Date
- Cost
- Status
- Activated yes/no
- Revenue generated

2. Track expenses
Categories:
- Marketing
- Rent
- Internet
- Utilities
- Salaries
- Commissions
- Software
- Travel
- Miscellaneous

3. Track revenue
- Customer
- Amount
- Employee responsible
- Lead source

4. Dashboard
Show:
- Revenue today
- Revenue this month
- Expenses today
- Expenses this month
- Profit today
- Profit this month
- Total leads
- Activated leads
- Conversion rate
- Cost per lead
- Cost per activated lead

5. Reports
- Daily report
- Weekly report
- Monthly report
- Lead source performance
- Employee performance

6. Charts
- Revenue trend
- Expense trend
- Profit trend
- Leads vs activated leads

Use a modern SaaS UI with dark mode and responsive design.
